GhostGram — Your World. Your Ghost.

This ZIP contains the updated Firebase starter with username + password signup and username login. Recovery email is optional. Read SETUP.txt before uploading the changed files to GitHub Pages.

Keep your existing firebase-config.js if it already contains your Firebase Web App configuration. Never add service-account JSON, private keys, passwords or OTPs.

This is a starter/demo. Posts, stories, reels and social interactions are not yet cloud-synced.
